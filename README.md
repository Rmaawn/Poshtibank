# پشتیبانک — Poshtibank

> **شعار:** همه پشتیبانی سایت، در یک افزونه

پشتیبانک (Poshtibank) یک افزونه چت آنلاین و پشتیبانی مشتریان برای وردپرس به صورت ۱۰۰٪ رایگان، متن‌باز (Open-Source) و بدون نیاز به سرور واسط (SaaS-Free) است. با اتصال مستقیم به پیام‌رسان‌های تلگرام و بله، پیام‌های کاربران سایت به آسانی به ربات‌های پشتیبانی ارسال شده و با Reply زدن ادمین در تلگرام یا بله، مستقیماً به کاربرِ داخل سایت پاسخ داده می‌شود.

---

## ویژگی‌های کلیدی
- **بدون سرور واسط (No SaaS):** داده‌ها مستقیماً در دیتابیس اختصاصی وردپرس ذخیره شده و به تلگرام و بله متصل می‌شوند.
- **دوگانه تلگرام و بله (Telegram & Bale Bridge):** ارسال و دریافت همزمان در تلگرام (`api.telegram.org`) و بله (`tapi.bale.ai`).
- **دور زدن تحریم و فیلترینگ تلگرام:** پشتیبانی توکار از Cloudflare Worker Reverse Proxy برای هاست‌های داخل ایران.
- **دیتابیس فوق بهینه:** استفاده از جداول اختصاصی `poshtibank_sessions` و `poshtibank_messages` با `dbDelta` بدون ایجاد بار روی جدول `wp_posts`.
- **پاکسازی خودکار (WP-Cron):** حذف هوشمند چت‌های قدیمی بر اساس بازه زمانی مشخص شده توسط مدیر سایت.
- **امنیت بالا:** حفاظت Nonce، Rate Limiting هوشمند بر اساس IP و نشست، Honeypot ضد اسپم، و فیلترینگ ورودی‌ها/خروجی‌ها.

---

## معماری شاخه‌ها و Git Workflow
- `main`: شاخه پایدار و آماده انتشار نسخه رسمی.
- `develop`: شاخه فعال توسعه فازها و ماژول‌ها.
- فرمت کامیت‌ها بر پایه **Conventional Commits**:
  - `feat(...)`: اضافه کردن قابلیت جدید
  - `fix(...)`: رفع باگ
  - `refactor(...)`: بازنویسی کد بدون تغییر در رفتار
  - `chore(...)`: کارهای عمومی و تنظیمات مخزن
  - `docs(...)`: مستندات

## نقشه راه ۷ فاز توسعه
1. **فاز ۱ (جاری):** طراحی ساختار دایرکتوری، Git، فایل اصلی افزونه، Activator/Deactivator و ایجاد جداول دیتابیس (`dbDelta`).
2. **فاز ۲:** ساخت پنل تنظیمات ادمین در وردپرس و ثبت وبهوک خودکار.
3. **فاز ۳:** هسته بک‌اند، REST API Endpoints و موتور ارتباطی Telegram و Bale.
4. **فاز ۴:** ویجت فرانت‌اند فوق سبک (Modular Vanilla JS & Modern CSS Variables).
5. **فاز ۵:** مالتی‌مدیا (ویس دوطرفه، اسکرین‌شات داخلی، ارسال فایل و تصویر).
6. **فاز ۶:** یکپارچگی عمیق با ووکامرس، پیام‌های پیشدستانه (Exit-Intent) و Deep Linking.
7. **فاز ۷:** هوش مصنوعی خط اول (BYOK AI Responder) و سیستم ضد اسپم.
